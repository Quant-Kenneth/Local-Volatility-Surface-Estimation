# Local Volatility Surface Estimation Using Nonparametric Methods

## Description
This project demonstrates the estimation of local volatility surfaces for **options pricing** using **nonparametric methods**. The method utilizes **Kernel Density Estimation (KDE)** to estimate the volatility surface without the need for a parametric model like Black-Scholes. This provides flexibility in modeling the **volatility smile** and **term structure** in real-world markets.

### Key Features:
- **Kernel Density Estimation** (KDE) to estimate local volatility surfaces.
- Extraction of **implied volatility** from **European call options** using **Black-Scholes** model and **Brent's method**.
- **Visualization** of volatility surfaces and implied volatility surfaces.
